# Qurexa Landing Page (JavaScript + TailwindCSS)

A senior-level, responsive healthcare landing page built with React, Vite, and TailwindCSS.

## 🚀 Quick Start
```bash
npm install
npm run dev
```

## 🧠 Features
- TailwindCSS utility-first styling
- Color palette based on Qurexa branding
- Modern responsive layout
- Clean component structure
- Ready for Figma visual exports

## 🌐 View
Visit `http://localhost:5173` after running dev server.
